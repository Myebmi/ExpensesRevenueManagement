# E&R Management | مدیریت عواید و مصارف

یک وب‌اپلیکیشن حرفه‌ای، امن و دو زبانه برای ثبت و مدیریت عواید و مصارف روزانه و کسب‌وکارهای کوچک.

## ✨ ویژگی‌های کلیدی
- **مدیریت معاملات:** ثبت، ویرایش، حذف و جستجوی پیشرفته عواید و مصارف.
- **داشبورد هوشمند:** محاسبه لحظه‌ای مجموع عواید، مصارف و بیلانس.
- **گزارش‌گیری:** مشاهده و دانلود گزارش‌ها در بازه زمانی دلخواه (CSV/Excel).
- **امنیت بالا:** سیستم احراز هویت با هش کردن رمز عبور (Passlib) و مدیریت Session.
- **دو زبانه:** پشتیبانی کامل از فارسی (RTL) و انگلیسی (LTR).
- **تاریخ شمسی:** نمایش تمام تاریخ‌ها به صورت شمسی.
- **واکنش‌گرا:** طراحی سازگار با موبایل، تبلت و کمپیوتر.

## 🛠️ فناوری‌های استفاده شده
- **Backend:** Python 3.12, FastAPI
- **Database:** PostgreSQL 16
- **ORM:** SQLAlchemy
- **Frontend:** HTML5, CSS3, Jinja2
- **Security:** Passlib (pbkdf2_sha256), Session Cookies
- **DevOps:** Docker, Docker Compose, Render (Deployment)
- **Testing:** Pytest
